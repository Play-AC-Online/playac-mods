# Changelog

What changes for people who make mods. This repository is generated, so each
sync is one commit. The lists below are the places to read what changed.

- **The mod API**, level by level: https://playaconline.com/modding/changelog/. This tree matches
  API level 1.
- **The `playac-mod` tool**, release by release: [`cli/CHANGELOG.md`](cli/CHANGELOG.md).
- **The game**: https://playaconline.com/releases/

## This repository

First release.

- The guides, the starter kits, the mod contract and the AI skill are written
  here, and a pull request to them can be merged. The mod contract is the full
  rule list the game checks every mod against.
- The API files, the errors list, the AI pack and the source of the
  `playac-mod` tool (`check`, `dev` and `pack`) are generated from the
  game. Share a mod from the website.
- Each example mod is its own repository, laid out like a mod repository of
  yours, and the README lists them. Start from one, or from a starter kit.
- The install line names one release of the tool and gives its SHA-256.
- A licence (MIT), this file, CONTRIBUTING.md, SECURITY.md and issue forms.
