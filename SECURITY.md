# Security

## What counts

Mods run inside limits. A mod cannot read your files, reach the internet,
change the game's code or touch another player's town. A way around any of
those is a security problem. So is a way to publish as someone else, or to
make the `playac-mod` tool run code from a mod it only checks.

A mod that is rude, broken or copied is not a security problem: use **Report**
on the mod's page in the game.

## How to report

Report it privately. Do not open a public issue and do not post the details
in public.

1. On GitHub: open the [Security tab](https://github.com/christophermarek/playac-mods/security) of this
   repository and choose **Report a vulnerability**.
2. Or on the game's Discord, https://discord.gg/7CrPXyX97m: ask a moderator for a private
   channel, and give the details only there.

Say what you did, what happened and what you expected. A mod ZIP that shows
it is the most useful thing you can send.

## What happens next

We answer within a few days. The fix is made in the game, and you are told
when it is live. Please give us that time before you write about it in public.
