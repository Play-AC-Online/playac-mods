# tools

Two scripts from the game's own build. You do not need either to make a mod.

- `example-textures.mjs` draws the pictures of the texture kit.
  It is here so you can see that they are drawn by a program and not copied
  from the game.
- `check-zip.mjs` checks a mod ZIP with the game's rules:
  `node tools/check-zip.mjs my-mod.zip`. `playac-mod check my-mod.zip`
  does the same and says more.
