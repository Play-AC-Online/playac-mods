My Textures

A starter kit for a texture mod.

Installed as it is, this kit turns the town grass into a bold two-green
check, from spring to autumn, so you see a texture mod work before you paint
anything. Delete those three pictures in textures/ when you paint your own.

First, open mod.json in any text editor. Change "yourname" in "id" and
"authors" to your own name (lower case letters, digits and dashes), and give
the mod a "name" and "description" of your own.

Then three steps:

1. In the model viewer, https://playaconline.com/viewer/, open the model,
   press Textures, then Save all. You get a ZIP with every texture of the
   model, each already named.
2. Paint over the pictures. Keep each file's name. Delete the ones you did
   not paint.
3. Drop them into textures/ and watch them change live: run playac-mod dev
   in this folder and connect the game to it. Without the tool, choose this
   folder in the game's developer mode, or ZIP the folder and install it from
   Settings, Mods, Install from a file, then Restart now.

Guide: https://playaconline.com/modding/guides/textures/
